3D: Код реальності — інтерактивний заліковий квест
Навчальний вебквест для 9 класу НУШ за § 4.1 «Тривимірна графіка. Принципи тривимірного моделювання» підручника Й. Ривкінда та ін. (2026).
Як відкрити
Двічі клацніть index.html. Інтернет не потрібен. Можна грати з комп'ютера або телефона.
Як опублікувати на GitHub Pages
1. Створіть публічний репозиторій GitHub, наприклад 3d-kvest-9.
2. Завантажте index.html та README.md у кореневу папку репозиторію (Add file → Upload files).
3. Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.
4. Посилання матиме вигляд https://ВАШ_ЛОГІН.github.io/3d-kvest-9/.
Залік
10 незалежних завдань, по 10 балів, 100 максимально. Одна зарахована відповідь на питання. Підсумок у 12-бальній шкалі за формулою max(1, round(балів * 12 / 100)). Є друк підсумку і TXT-звіт. Це навчальна гра без сервера: учитель отримує результати тільки якщо учні надсилають файл / показують екран. Учні можуть перезапустити гру; для контрольованого заліку проводьте її у присутності вчителя.
Налаштування
Усі питання містяться у масиві tasks всередині index.html. Кожне питання має q, opts, answer (індекс правильної відповіді від 0 до 3), why, visual.
Джерело теми
§ 4.1 підручника «Інформатика. 9 клас» (Ривкінд та ін., видання 2026), стор. 141–151. Гра містить авторські ситуаційні завдання, а не копії вправ.
